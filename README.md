# Ficha de Evaluación Socioeconómica · IESTP Nuñoa

Formulario en línea del **Anexo N° 03 – Ficha de Evaluación Socioeconómica (Declaración Jurada)**
del Instituto de Educación Superior Tecnológico Público Nuñoa.

- `index.html` — formulario público para los estudiantes. Al guardar, descarga la ficha en Word para imprimir y firmar.
- `admin.html` — panel del área de Bienestar y Empleabilidad (requiere clave): registros, estadísticas, Word, edición y Excel.

**Este repositorio no contiene datos de estudiantes.** Las fichas se guardan en una hoja de cálculo
privada de Google mediante Google Apps Script (`google-apps-script/Code.gs`, que no se publica aquí).

La URL del backend se configura en `js/config.js`.
